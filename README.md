# Grid playground (LU47 lesson sandbox)

A tiny, explore-only StackBlitz sandbox for the LU47 Grid Fundamentals learning unit. Six tiles in a grid; students change one value at a time (column count, gap, auto-fit, a span) and watch the layout rearrange. **Nothing is submitted from it** - it is separate from, and much simpler than, the graded Campus Dashboard PMF assignment.

## Files

- `index.html` - six `.tile` boxes inside a `.grid`.
- `style.css` - the grid rules, with inline prompts for what to try.
- `package.json` - Vite, so StackBlitz boots it as a live project.

## Publish for the lesson embed

Push these files to the public repo **`kalviumcommunity/wad-grid-playground`** (branch `main`). The lesson embeds it as:

```
https://stackblitz.com/github/kalviumcommunity/wad-grid-playground?embed=1&file=style.css&hideNavigation=1&view=default
```
